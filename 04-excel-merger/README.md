# Excel 批量合并

把一个文件夹里所有 Excel 表格合成一张总表，一条命令搞定。

适合：每天/每周收上来一堆格式相同的表格，要拼成一张再统计。

## 快速开始

```bash
pip install pandas openpyxl

python excel_merge.py -i ./订单表
# 输出：./订单表/合并结果.xlsx
```

## 常用参数

```bash
python excel_merge.py -i ./订单表 -o 汇总.xlsx    # 指定输出文件
python excel_merge.py -i ./订单表 -r               # 递归子文件夹
python excel_merge.py -i ./订单表 -s Sheet1        # 只合并指定工作表
python excel_merge.py -i ./订单表 --no-source      # 不加“来源文件”列
```

## 它处理了哪些脏活

| 情况 | 行为 |
|------|------|
| 表头顺序/数量不一致 | 取并集，缺的格子留空 |
| 有空表混在里面 | 跳过，最后列出来 |
| Excel 打开时的 `~$` 临时文件 | 跳过 |
| 某个文件损坏读不了 | 跳过该文件，不中断整批 |
| 输出文件放在输入目录里 | 自动排除，重复运行不会把结果又合并一遍 |
| 文件夹里有子目录 | 默认不递归，`-r` 打开 |
| 输出名没写后缀 | 自动补 `.xlsx` |

## 输出长什么样

```
找到 4 个表格，开始合并……

  已读取 1月.xlsx                    2 行 × 4 列
  已读取 2月.xlsx                    1 行 × 5 列
  已读取 3月.xlsx                    3 行 × 4 列

合并完成：6 行 × 5 列
输出文件：D:\订单表\合并结果.xlsx

跳过了 1 个文件：
  - 空表.xlsx（空表）
```

合并结果的每一行都带「来源文件」列，方便回溯这条数据来自哪个表。

## 已知限制

- **不支持 `.xls`**（2003 老格式）：需要先另存为 `.xlsx`，或额外装 `xlrd`
- **只读第一个工作表**：多 sheet 的表格请用 `-s` 指定
- **一次性全部读进内存**：几万行没问题，上百万行建议改用分批 `chunksize` 或直接上数据库

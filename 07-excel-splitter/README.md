# Excel 按列拆分

一张总表，按某一列拆成几十个独立文件。

适合：按部门/地区/客户分发、按月份拆账、按分类拆报表。

## 快速开始

```bash
pip install pandas openpyxl

python split_excel.py -i 总表.xlsx -c 客户
# 输出：总表_拆分/ 目录，每个客户一个 xlsx
```

## 常用参数

```bash
python split_excel.py -i 总表.xlsx -c 地区 -o 输出目录   # 指定输出目录
python split_excel.py -i 总表.xlsx --rows 500            # 每 500 行一个文件
python split_excel.py -i 总表.xlsx -c 部门 --no-index     # 不保留拆分类
python split_excel.py -i 总表.xlsx -c 客户 -s Sheet2      # 指定工作表
```

## 处理了哪些情况

| 情况 | 行为 |
|------|------|
| 单元格内容含 `/ : * ? " < > \|` | 自动替换为下划线，不会命名失败 |
| 内容超长 | 截到 40 字，防止路径超限 |
| 空值 | 归到「未填写.xlsx」 |
| 拆出同名文件 | 自动加 `_2`、`_3` 后缀，不覆盖 |
| 表头有空格的列名 | 统一去掉首尾空格 |
| 只想按行切块 | 用 `--rows 500`，不用指定列 |

## 输出长什么样

```
读取 合并结果.xlsx（8152 行 × 6 列）

按「客户」拆分……

  何静.xlsx                         376 行
  刘洋.xlsx                         422 行
  ...
拆分完成：20 个文件
输出目录：D:\总表_拆分
```

默认拆出来的文件**不包含**用来拆分的列（比如按客户拆，客户列就不重复带了），
需要保留就加 `--no-index`。

## 已知限制

- 不支持 `.xls` 老格式，先另存为 `.xlsx`
- 数据量特别大（几十万行）时按行拆分建议 `--rows` 控制在 5 万以内，避免单个文件过大
- 只处理第一个工作表，多 sheet 用 `-s` 指定

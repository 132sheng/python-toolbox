# PyType Lite · Python 打字闯关

练 Python 关键字和符号手速的单文件网页小游戏。

## 运行

双击 `index.html`，或用任意静态服务器托管：

```bash
python -m http.server 8000
# 打开 http://localhost:8000/01-typing-game/
```

## 功能

- **逐题计时**：每题独立计时，拼速度与准确率
- **三档关卡**：基础 → 关键字 → 符号，按累计得分逐级解锁
- **实时反馈**：得分、连击、正确率，答错即断连击
- **成绩记录**：最高分用 localStorage 存在本地，刷新不丢
- **零依赖**：36 KB 单文件，无 CDN、无构建、无框架

## 技术说明

纯原生 HTML + CSS + JavaScript，状态机驱动题目流转，无第三方库。

界面做了移动端适配，手机上也能玩。

# 考研分数线看板

把散落在网页上的院校复试分数线，变成能筛选、能对比的交互式看板。

## 快速开始

```bash
pip install -r ../requirements.txt
python analyze.py
# 生成 dashboard.html，浏览器打开即可
```

## 常用命令

```bash
python analyze.py                      # 全部数据，TOP 12 院校
python analyze.py --top 20             # 只看前 20 所
python analyze.py --year 2024          # 只分析 2024 年
python analyze.py --school 清华大学      # 查单个院校的专业明细
python analyze.py --output out.html    # 指定输出路径
```

终端会同时打印统计表格：

```
数据范围：2023–2026，共 5791 条记录，20 所院校

=== 平均总分 TOP 12 ===
      学校  平均总分  最高总分  最低总分  专业数  记录数
  中国政法大学 347.8   390   146   95  315
  中国人民大学 344.6   420   135  123  445
...
```

## 做了什么

1. **清洗**：分数列转数值（`errors="coerce"`）、年份转整型、剔除关键字段缺失的行
2. **聚合**：按院校算平均分 / 最高分 / 最低分 / 专业覆盖数；按年份算趋势
3. **可视化**：横向柱状图（TOP N 院校）+ 折线图（年度趋势），拼成一页看板
4. **离线可用**：自带 `assets/echarts.min.js`，不走 CDN，断网也能看

## 数据说明

| 字段 | 含义 |
|------|------|
| 学校 / 专业 / 代码 | 院校与专业信息 |
| 招生院系 | 招生单位 |
| 总分 | 复试分数线总分 |
| 政治 / 外语 / 专业课一 / 专业课二 | 单科线 |
| 录取年份 | 2023–2026 |

共 20 所院校、5791 条记录，取自公开页面，仅用于学习与技术演示。

## 目录

```
analyze.py                  # 主程序：加载 → 清洗 → 统计 → 出图
data/kaoyan_scores.csv      # 原始数据（UTF-8）
assets/echarts.min.js       # 离线图表库
dashboard.html              # 生成结果
```

## 可以怎么改

- 换数据源：只要 CSV 保持同样的表头，`load_data()` 不用动
- 加维度：按「招生院系」聚合、按「政治/外语单科线」筛人
- 加图表：pyecharts 的 `Pie` / `Map` 直接 `page.add()` 即可

> 采集脚本没有放进仓库：目标是演示数据处理与可视化，不是提供爬取工具。
> 需要定制采集 + 分析，可以开 Issue 聊。
